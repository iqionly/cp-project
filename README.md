## REQUIREMENTS

Install this requirements:

- docker engine
- git
- (optional) docker desktop

## PREPARATION

After you install docker, run this command:

```bash
git clone https://github.com/iqionly/cp-project.git
cd cp-project
docker compose up -d --build --force-recreate
```

After finished the commands above, open your chrome and open link ```http://127.0.0.1```

NOTES: Make sure no service or process running with port 80, 443 and 3306
